# 20_voice_drift_check

## 사용 목적

주요 인물의 말투가 AI에 의해 서서히 변질(drift)되고 있는지 감지하고, 의도적 성장과 비의도적 drift를 구별해 기록합니다. 10화마다 정기 실행하거나 말투가 이상하다고 느껴질 때 즉시 실행합니다.

---

## 실행 타이밍

| 상황 | 대상 인물 | 긴급도 |
|---|---|---|
| 10화 완료마다 | 모든 주요 인물 | 정기 (필수) |
| arc 종료 시 | 모든 주요 인물 | 정기 (필수) |
| "이 대사가 이상하다"고 느낄 때 | 해당 인물 | 즉시 |
| 사용자가 말투에 대한 피드백을 남길 때 | 해당 인물 | 즉시 |
| 두 인물의 대사가 비슷해 보일 때 | 두 인물 모두 | 즉시 |

## 실행 전 준비 파일

- [ ] `voice_samples.md` — 초기 기준 샘플 확인
- [ ] `voice_evolution_log.md` — 이전 체크포인트 확인 (있다면)
- [ ] `character_bible.json` — 인물 성격, 말투 특징 확인
- [ ] 최근 5화 원고 (해당 인물 대사 추출용)

## 실행 단계 (주요 인물 1인당 반복)

### 단계 1 — 기준 샘플 확인

`voice_samples.md`에서 해당 인물의 초기 샘플을 읽는다.

`voice_evolution_log.md`에 이전 체크포인트가 있다면 **가장 최근 체크포인트 샘플**을 기준으로 사용한다. (체크포인트가 있으면 초기 샘플 대신 최근 체크포인트와 비교)

**기준에서 추출할 항목**:
- 이 인물의 서명 표현 (3~5개)
- 특유의 문장 구조 (짧고 끊기는 / 긴 설명형 / 질문형 등)
- 감정 처리 방식 (감정을 감추는 / 직접 표현하는 / 행동으로 보여주는 등)
- 어휘 특성 (전문 용어 선호 / 단순한 단어 / 특정 시대 어투 등)

---

### 단계 2 — 현재 샘플 추출

최근 5화 원고에서 해당 인물의 대사 또는 내면 독백을 3~5개 추출한다. 가능하면 감정이 드러나는 장면의 대사를 선택한다.

---

### 단계 3 — 비교 분석

|---|---|---|---|
| 서명 표현 등장 여부 | {{있음}} | {{있음/없음}} | ☐ |
| 문장 구조 패턴 | {{짧고 끊기는 등}} | {{}} | ☐ |
| 감정 처리 방식 | {{감추는 편}} | {{}} | ☐ |
| 어휘 특성 | {{}} | {{}} | ☐ |
| 다른 인물과의 구별도 | {{높음}} | {{높음/낮음}} | ☐ |

### 단계 4 — 판정

아래 기준으로 판정한다.

**AI Drift** — 수정 대상:
- 서명 표현이 5화 이상 등장하지 않음
- 문장 구조 또는 감정 처리 방식이 크게 달라짐
- 이 변화를 설명할 만한 사건이 없음
- 두 인물의 대사가 이름을 가려도 구별되지 않음

**의도적 성장** — 기록 후 유지:
- 변화의 계기가 될 사건이 명확히 발생함
- 사용자가 변화를 승인함
- `voice_evolution_log.md`에 기록되고 `voice_samples.md`가 업데이트됨

**정상 범위**:
- 서명 표현이 유지됨
- 감정 처리 방식이 일관됨
- 변화가 있더라도 이전 체크포인트 대비 소폭이며 납득 가능함

---

### 단계 5 — 기록

#### 정상 또는 의도적 성장인 경우

`voice_evolution_log.md`의 해당 인물 섹션에 체크포인트를 추가한다.

```
**체크포인트 #{{N}} — EP{{N}} (YYYY-MM-DD)**

대표 대사 샘플:
[대사 2~3줄]

변화 여부: 없음 / 있음

판단: 정상 범위 / 의도적 성장
조치: — / intentional_changes 기록 + voice_samples.md 업데이트
```

#### Drift로 판정된 경우

1. `voice_evolution_log.md`의 `drift_flags` 표에 기록
2. `voice_correction_note` 작성 (아래 형식)
3. 사용자에게 보고 후 revision 범위 확인

**voice_correction_note 형식**:

```
[VOICE_CORRECTION_NOTE — {{character_id}} — EP{{N}}]

drift 감지:
- 서명 표현 {{N}}화 미등장: {{서명 표현명}}
- 변화 내용: {{구체적으로 어떻게 달라졌는가}}
- 비교 기준: voice_evolution_log 체크포인트 #{N} 또는 voice_samples.md 초기 샘플

수정 필요 범위:
- EP{{시작}} ~ EP{{현재}}의 {{인물명}} 대사

수정 방향:
- {{어떤 표현을 회복해야 하는가}}
- {{피해야 할 현재 패턴}}

사용자 승인 필요 여부: {{예/아니요}}
```

## 전체 인물 구별도 체크 (선택적 — 말투 수렴 의심 시)

모든 주요 인물의 최근 대사를 이름 없이 나열하고 아래를 확인한다.

- [ ] 각 대사가 누구의 것인지 구별 가능한가?
- [ ] 두 인물이 동일 상황에서 유사한 방식으로 반응하고 있지 않은가?

구별이 어렵다면 → 구별이 어려운 두 인물에 대해 drift 감지 절차를 각각 실행.

```
결과:
- {{character_id}}: 정상 범위

- {{character_id}}: AI drift 감지 → voice_correction_note 작성 완료

voice_evolution_log.md 체크포인트 #{N} 추가: 완료
voice_samples.md 업데이트: 있음/없음

사용자 확인 필요: {{있음/없음}}
```
