# VOICE_DRIFT_HARNESS

AI가 장기 연재에서 인물의 말투를 서서히 균질화하는 경향(Voice Drift)을 감지하고 교정하는 harness입니다.

---

## 목적

AI는 수십 화를 작성하는 동안 캐릭터들의 말투를 점차 비슷하게 만드는 경향이 있습니다. 이 harness는 그 현상을 조기에 감지하고, 의도적 성장과 무의식적 drift를 명확히 구별하며, 각 인물의 고유한 목소리를 끝까지 지키는 것을 목표로 합니다.

---

## 실행 트리거

다음 중 하나에 해당하면 이 harness를 실행한다.

| 트리거 | 대상 인물 | 설명 |
|---|---|---|
| 10화 완료마다 | 모든 주요 인물 | 정기 점검. LONGFORM_HARNESS의 10화 audit에 포함. |
| arc 종료 시 | 모든 주요 인물 | CONTEXT_COMPRESSION_HARNESS와 함께 실행. |
| 작업자가 "이 대사가 이상하다"고 느낄 때 | 해당 인물 | 즉시 실행. |
| 사용자 피드백 중 말투 관련 지적이 있을 때 | 해당 인물 | 즉시 실행. |
| 새 회차 review에서 인물 구별이 어렵다고 느낄 때 | 전체 | 즉시 실행. |

## Drift vs. 성장 판단 기준

### AI Drift (비의도적 — 수정 대상)

다음 신호 중 2개 이상이 동시에 감지되면 drift로 판단한다.

| 신호 | 판단 방법 |
|---|---|
| **어휘 범용화** | 캐릭터 특유 어휘가 사라지고 "어", "그래", "알겠어" 같은 일반 표현으로 대체됨 |
| **서명 표현 소멸** | voice_samples.md에 기록된 말버릇, 구조, 관용어가 5화 이상 등장하지 않음 |
| **감정 레지스터 불일치** | 같은 자극에 대해 이전과 크게 다른 강도 또는 방식으로 반응 |
| **호흡 패턴 변화** | 짧게 끊던 인물이 장문을 구사하거나, 냉철한 인물이 갑자기 감정적으로 서술 |
| **사건 없는 점진적 변화** | 성격 변화를 설명할 사건이 없는데 말투가 달라짐 |
| **인물 간 말투 수렴** | 두 인물의 대사를 섞어놓아도 누가 누구인지 구별하기 어려움 |

### 의도적 성장 (캐릭터 발전 — 기록 후 유지)

다음 조건이 **모두** 충족되어야 성장으로 인정한다.

- [ ] 변화의 계기가 될 사건이 명확히 발생했다
- [ ] 사용자가 변화를 명시적으로 승인했거나 묵시적으로 동의했다
- [ ] `voice_evolution_log.md`의 `intentional_changes`에 기록되었다
- [ ] 변화 후 새 voice_sample이 `voice_samples.md`에 추가되었다

## 감지 방법 (Detection Method)

### 1단계 — 기준 샘플 수집

다음 파일에서 현재 기준 샘플을 가져온다:
1. `voice_samples.md` — 초기 설정 샘플
2. `voice_evolution_log.md` — 이전 체크포인트의 샘플 (있다면)

비교 기준: 가장 최근 체크포인트 샘플. 체크포인트가 없으면 초기 샘플.

### 2단계 — 현재 샘플 추출

최근 5화에서 해당 인물의 대사 또는 내면 독백을 3~5개 추출한다. 최대한 긴 대사를 선택한다.

### 3단계 — 비교 분석

다음 항목을 기준 샘플과 비교한다:

| 비교 항목 | 확인 질문 |
|---|---|
| 어휘 | 특유의 어휘가 유지되는가? 범용 표현으로 대체되지 않았는가? |
| 서명 표현 | voice_samples.md의 서명 표현이 최근 5화에 최소 1회 이상 등장했는가? |
| 문장 구조 | 짧게 끊거나 길게 이어지는 패턴이 유지되는가? |
| 감정 처리 방식 | 같은 유형의 자극에 일관되게 반응하는가? |
| 인물 구별도 | 이 대사를 다른 인물의 것으로 바꿔도 어색하지 않은가? (어색해야 정상) |

### 4단계 — 판정 및 기록

판정 결과를 `voice_evolution_log.md`의 해당 인물 섹션에 체크포인트로 기록한다.

---

## 조치 (Corrective Action)

### Drift로 판정된 경우

1. **voice_correction_note 작성**: 어떤 대사/표현이 문제이며 어떻게 수정해야 하는지 구체적으로 기술
2. **revision 범위 결정**: drift가 시작된 화부터 현재까지 해당 인물의 대사 수정 범위 확인
3. **수정 전 사용자 보고**: "{{인물명}}의 말투 drift가 EP{{N}}부터 감지됩니다. 수정 범위: EP{{N}}~EP{{M}}. 사용자 확인 후 revision 진행합니다."
4. **voice_evolution_log 업데이트**: drift_flags 섹션에 기록
5. **수정 완료 후**: voice_samples.md의 해당 인물 섹션을 현재 기준으로 갱신 (단, 의도적 성장이 아닌 경우에는 초기 버전 유지)

### 의도적 성장으로 판정된 경우

1. `voice_evolution_log.md`의 `intentional_changes` 섹션에 기록
2. `voice_samples.md`에 새 체크포인트 샘플 추가
3. 이후 비교 기준을 새 샘플로 갱신

## 회차 draft 검토 체크리스트

새 회차 draft를 작성하거나 검토할 때 주요 인물 대사에 대해 아래를 확인한다.

### 주인공 체크

- [ ] 주인공의 서명 표현이 이번 화에 자연스럽게 등장했는가?
- [ ] 주인공의 감정 처리 방식이 이전 체크포인트와 일치하는가?
- [ ] 주인공이 지나치게 설명적이거나 지나치게 단순해지지 않았는가?

### 주요 조연 체크 (주요 등장 화)

- [ ] 조연의 말투가 주인공과 충분히 구별되는가?
- [ ] 조연의 서명 표현 또는 특유 구조가 포함되었는가?

### 적대자/빌런 체크 (등장 화)

- [ ] 빌런의 말투가 단순 "악당스럽게" 변하지 않았는가?
- [ ] 빌런 고유의 어조와 논리가 유지되는가?

### 전체 대사 구별도 체크

- [ ] 이 화의 대사를 캐릭터 이름 없이 읽어도 누가 누구인지 구별 가능한가?

## 보고 형식

Voice Drift Harness 실행 후 다음 형식으로 보고한다.

```
[VOICE_DRIFT_CHECK — EP{{N}}]
점검 인물: {{character_id_list}}
기준 샘플: voice_samples.md EP{{기준}}
비교 샘플: EP{{N-4}} ~ EP{{N}}

결과:
- {{character_id}}: 정상 / drift 감지 / 성장 기록
  (drift 시 구체 내용과 수정 계획)
  (성장 시 계기 사건과 기록 완료 여부)

조치:
- voice_evolution_log.md 체크포인트 #{N} 추가 완료
- voice_correction_note: {{있음/없음}}
- voice_samples.md 업데이트: {{있음/없음}}
```

## 관련 파일

- `voice_samples.md` (초기 기준 샘플)
- `voice_evolution_log.md` (체크포인트 및 drift 기록)
- `character_bible.json` (인물 성격/말투 기준)
- `LONGFORM_HARNESS.md` (10화 audit 연계)
- `THEMATIC_HARNESS.md` (주제 관련 인물 변화 연계)

---

## 중단 조건

- 주요 인물의 drift가 확인되었으나 voice_correction_note 없이 final 저장하려는 경우
- `halt_reason_code: VOICE_DRIFT_UNRESOLVED`
