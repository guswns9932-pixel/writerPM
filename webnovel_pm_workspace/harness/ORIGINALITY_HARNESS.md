# ORIGINALITY_HARNESS

기존 작품 모방 위험과 표절성 유사성을 방지하기 위한 문서형 harness입니다.

## 목적

- 기존 작품 고유 설정 모방 방지
- 기존 작품 고유 용어 모방 방지
- 기존 작품 대표 장면 모방 방지
- 특정 작가 문체 모방 방지
- 장르 클리셰와 표절성 유사성 구분

## 금지 항목

다음은 사용하지 않습니다.

- 특정 기존 작품에서 식별 가능한 고유 설정
- 특정 기존 작품의 고유 명칭, 시스템명, 조직명, 능력명
- 특정 기존 작품을 대표하는 장면 구조나 연출
- 특정 작가의 문장 리듬, 비유 습관, 대사 스타일을 겨냥한 문체 모방
- 사용자가 요청하더라도 특정 작품의 장면을 사실상 재현하는 방식

## 허용 항목

다음은 장르 문법으로 활용할 수 있습니다.

- 회귀, 빙의, 상태창, 탑 등 널리 쓰이는 장르 장치
- 성장, 복수, 생존, 계약, 경쟁, 학원, 헌터물 등 일반 장르 구조
- 클리프행어, 반전, 던전, 랭킹, 스킬 성장 등 보편적 연재 문법

단, 고유 조합과 표현은 새롭게 만들어야 합니다.

## 장르 클리셰와 표절성 유사성 구분

### 장르 클리셰

- 여러 작품에서 반복되는 일반 구조다.
- 특정 작품 하나를 바로 떠올리게 하지 않는다.
- 명칭, 장면, 전개, 문체가 독자적으로 변주되어 있다.

### 표절성 유사성 위험

- 특정 작품의 고유 명칭이나 설정을 떠올리게 한다.
- 대표 장면의 순서, 갈등, 대사 기능이 유사하다.
- 특정 작가의 문체를 목표로 삼았다.
- 장르 문법이 아니라 식별 가능한 조합까지 유사하다.

## 검수 질문

- [ ] 이 설정은 특정 작품 하나의 고유 설정처럼 보이지 않는가?
- [ ] 이 용어는 기존 작품의 고유 명칭과 충분히 다른가?
- [ ] 이 장면은 특정 작품의 대표 장면을 재현하지 않는가?
- [ ] 문체 지시가 특정 작가 모방으로 해석되지 않는가?
- [ ] 장르 클리셰를 사용했다면 새로운 조합, 목표, 감정선, 해결 방식을 추가했는가?

## 위험 발견 시 처리

1. 문제 후보를 review에 기록한다.
2. final 저장을 중단한다.
3. 대체 설정, 대체 용어, 대체 장면 구조를 제안한다.
4. 특정 작품명 기반 모방 요청은 거절하고 장르적 특징 수준으로 재해석한다.
