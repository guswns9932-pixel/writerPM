# QUALITY_HARNESS

회차의 상업적 재미와 독자 유지력을 점검하기 위한 문서형 harness입니다.

## 검수 목적

- 첫 500자 후킹 확인
- 장면별 갈등 확인
- 주인공 선택 확인
- 독자 보상 확인
- 모바일 가독성 확인
- 클리프행어 확인
- 상업성 확인
- 장면 삭제 가능성 평가

## 첫 500자 후킹

- [ ] 첫 500자 안에 독자가 계속 읽을 질문이 생긴다.
- [ ] 주인공의 결핍, 위험, 욕망, 비밀 중 하나가 드러난다.
- [ ] 설명보다 사건, 선택, 충돌, 이상 징후로 시작한다.
- [ ] 장르 기대감을 빠르게 전달한다.

## 장면별 갈등

각 장면마다 최소 하나를 포함해야 합니다.

- [ ] 인물 간 목표 충돌
- [ ] 주인공의 선택 압박
- [ ] 정보 비대칭
- [ ] 위험 증가
- [ ] 감정 변화
- [ ] 보상 또는 손실

## 주인공 선택

- [ ] 주인공이 수동적으로 끌려가기만 하지 않는다.
- [ ] 회차 안에서 의미 있는 선택을 한다.
- [ ] 선택에는 대가 또는 결과가 있다.
- [ ] 선택이 다음 사건을 밀어낸다.

## 독자 보상

- [ ] 회차 안에서 정보, 감정, 승리, 반전, 성장 중 하나 이상의 보상이 있다.
- [ ] 독자가 기다린 장면이 일부라도 충족된다.
- [ ] 보상이 다음 궁금증을 완전히 소모하지 않는다.

## 모바일 가독성

- [ ] 문단이 과도하게 길지 않다.
- [ ] 대사와 행동이 화면에서 빠르게 읽힌다.
- [ ] 정보 설명이 한 번에 몰리지 않는다.
- [ ] 장면 전환이 명확하다.

## 클리프행어

- [ ] 회차 마지막에 다음 화를 읽을 이유가 있다.
- [ ] 위기, 선택, 비밀 공개 직전, 반전, 보상 예고 중 하나를 포함한다.
- [ ] 억지로 끊은 느낌이 아니라 회차 목표와 연결된다.

## 상업성

- [ ] 장르 독자가 기대하는 핵심 재미가 드러난다.
- [ ] 주인공의 매력 또는 응원 이유가 있다.
- [ ] 반복 독서를 유도할 장기 목표가 보인다.
- [ ] 플랫폼형 연재 속도감이 유지된다.

## 장면 삭제 가능성 평가

각 장면에 대해 다음 질문을 적용합니다.

- [ ] 이 장면이 사라지면 줄거리 이해가 어려워지는가?
- [ ] 이 장면이 사라지면 인물 감정선이 약해지는가?
- [ ] 이 장면이 사라지면 복선, 보상, 갈등 중 하나가 손상되는가?
- [ ] 세 질문 모두 “아니오”라면 삭제 또는 압축 후보로 표시한다.

## 품질 이슈 처리

- 핵심 품질 이슈가 있으면 review에 기록한다.
- 자동 수정은 기본 1회만 수행한다.
- 추가 수정이 필요하면 revision_note를 남기고 사용자 지시를 기다린다.

## High-risk 품질 추세 기록

- 회차별 품질 점수는 `quality_trend_log.json` 또는 해당 역할 문서에 누적합니다.
- 회차별 독자 보상 유형은 `reader_reward_ledger.json` 또는 해당 역할 문서에 기록합니다.
- 같은 독자 보상 유형이 3회 이상 반복되면 다음 회차 변주 계획을 작성합니다.
- 총점 75점 미만 또는 독자 보상 누락은 revision_note 없이 final 저장할 수 없습니다.
