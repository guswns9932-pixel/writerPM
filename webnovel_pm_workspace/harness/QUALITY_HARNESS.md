# QUALITY_HARNESS

회차의 상업적 재미와 독자 유지력을 점검하기 위한 문서형 harness입니다.

## 검수 목적

- 첫 500자 후킹 확인
- 장면별 갈등 확인
- 주인공 선택 확인
- 독자 보상 확인
- 모바일 가독성 확인
- 클리프행어 확인
- 상업성 확인
- 장면 삭제 가능성 평가

## 첫 500자 후킹

- [ ] 첫 500자 안에 독자가 계속 읽을 질문이 생긴다.
- [ ] 주인공의 결핍, 위험, 욕망, 비밀 중 하나가 드러난다.
- [ ] 설명보다 사건, 선택, 충돌, 이상 징후로 시작한다.
- [ ] 장르 기대감을 빠르게 전달한다.

## 장면별 갈등

각 장면마다 최소 하나를 포함해야 합니다.

- [ ] 인물 간 목표 충돌
- [ ] 주인공의 선택 압박
- [ ] 정보 비대칭
- [ ] 위험 증가
- [ ] 감정 변화
- [ ] 보상 또는 손실

## 주인공 선택

- [ ] 주인공이 수동적으로 끌려가기만 하지 않는다.
- [ ] 회차 안에서 의미 있는 선택을 한다.
- [ ] 선택에는 대가 또는 결과가 있다.
- [ ] 선택이 다음 사건을 밀어낸다.

## 독자 보상

- [ ] 회차 안에서 정보, 감정, 승리, 반전, 성장 중 하나 이상의 보상이 있다.
- [ ] 독자가 기다린 장면이 일부라도 충족된다.
- [ ] 보상이 다음 궁금증을 완전히 소모하지 않는다.

## 모바일 가독성

- [ ] 문단이 과도하게 길지 않다.
- [ ] 대사와 행동이 화면에서 빠르게 읽힌다.
- [ ] 정보 설명이 한 번에 몰리지 않는다.
- [ ] 장면 전환이 명확하다.

## 클리프행어

- [ ] 회차 마지막에 다음 화를 읽을 이유가 있다.
- [ ] 위기, 선택, 비밀 공개 직전, 반전, 보상 예고 중 하나를 포함한다.
- [ ] 억지로 끊은 느낌이 아니라 회차 목표와 연결된다.

## 상업성

- [ ] 장르 독자가 기대하는 핵심 재미가 드러난다.
- [ ] 주인공의 매력 또는 응원 이유가 있다.
- [ ] 반복 독서를 유도할 장기 목표가 보인다.
- [ ] 플랫폼형 연재 속도감이 유지된다.

## 장면 삭제 가능성 평가

각 장면에 대해 다음 질문을 적용합니다.

- [ ] 이 장면이 사라지면 줄거리 이해가 어려워지는가?
- [ ] 이 장면이 사라지면 인물 감정선이 약해지는가?
- [ ] 이 장면이 사라지면 복선, 보상, 갈등 중 하나가 손상되는가?
- [ ] 세 질문 모두 “아니오”라면 삭제 또는 압축 후보로 표시한다.

## 문장 리듬 검사 (AI 문체 제거)

### 검사 항목

**문장 길이 균형**
- [ ] 같은 문장 길이가 5문장 이상 반복되는가?
- [ ] 짧은 문장, 중간 문장, 긴 문장이 자연스럽게 섞여 있는가?

**종결사 다양성**
- [ ] "~다." 종결이 8문장 이상 연속되는가?
- [ ] "~었다", "~았다", "~네", "~야" 등 다양한 종결이 있는가?

**AI식 문장 감지**
- [ ] 의미 라벨링 문장이 있는가? ("이것이 첫 선택이다", "소멸의 냄새")
- [ ] 추상어가 단독 문장으로 쓰였는가?
- [ ] 명사 단독 문장이 3번 이상 연속되는가?

**감각과 감정 표현**
- [ ] 감각 묘사가 설명문처럼 분리되어 있는가?
- [ ] 감정이 선언되어 있는가? ("심장이 뛴다. 두려움이 몰려왔다.")
- [ ] 신체 반응이나 상황으로 감정이 보여지고 있는가?

**장면 흐름**
- [ ] 대사 앞뒤가 부자연스럽게 끊겼는가?
- [ ] 전투 장면이 동작 나열인가?
- [ ] 장면 제목이나 의미 선언이 본문에 있는가?

## 품질 이슈 처리

- 핵심 품질 이슈가 있으면 review에 기록한다.
- 자동 수정은 기본 1회만 수행한다.
- 추가 수정이 필요하면 revision_note를 남기고 사용자 지시를 기다린다.

### 리듬 이슈 처리 기준

- 기계적 단문 반복 (5회 이상): **필수 수정**
- 의미 라벨링 문장: **필수 제거**
- 감각 설명문: **필수 통합**
- 감정 선언: **필수 변환**
- AI식 표현: **필수 개선**

## High-risk 품질 추세 기록

- 회차별 품질 점수는 `quality_trend_log.json` 또는 해당 역할 문서에 누적합니다.
- 회차별 독자 보상 유형은 `reader_reward_ledger.json` 또는 해당 역할 문서에 기록합니다.
- 같은 독자 보상 유형이 3회 이상 반복되면 다음 회차 변주 계획을 작성합니다.
- 총점 75점 미만 또는 독자 보상 누락은 revision_note 없이 final 저장할 수 없습니다.

## Reader reward trend gate

- 각 회차의 독자 보상 유형을 `reader_reward_ledger.json`에 기록한다.
- 최근 3화의 보상 유형이 반복되면 다음 회차 outline에서 다른 보상 유형을 우선 검토한다.
- 클리프행어 유형이 반복되면 `episode_pattern_log.json` 또는 해당 역할 문서에 반복 위험을 기록한다.
- quality score가 통과라도 독자 보상 또는 클리프행어가 약하면 final 저장 전 revision_note를 작성한다.
