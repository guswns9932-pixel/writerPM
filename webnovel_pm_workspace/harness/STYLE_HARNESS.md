# STYLE_HARNESS: AI 문체 제거 & 자연스러운 웹소설 문체

**목표**: "사람이 쓴 것처럼 자연스럽고, 장면이 실제로 흐르는 웹소설 문체"
**아님**: 화려한 표현, 문학적 치장, 설명식 감정 표현

---

## 1. 기계적 단문 반복 금지

### 규칙
- 같은 구조의 단문을 3번 이상 연속 사용 금지
- "명사. 명사. 명사." 식의 끊어 쓰기 남발 금지
- "~했다. ~했다. ~했다." 식의 일렬 나열 금지
- 문장 길이: 짧은 문장, 중간 문장, 긴 문장이 자연스럽게 섞임

### 체크리스트
- [ ] 같은 문장 구조가 3번 이상 연속되는가?
- [ ] 단독 명사 문장이 3번 이상 연속되는가?
- [ ] 모든 문장이 비슷한 길이인가?

### 나쁜 예
```
탑승하는 순간 코가 깨어난다.
낯선 냄새가 있다.
두 가지다. 하나는 익숙하다. 사람. 땀, 향수, 세제.
```

### 좋은 예
```
탑승하는 순간 코가 깨어난다. 낯선 냄새가 있다.
하나는 익숙했다. 사람. 땀, 향수, 세제. 무시할 수 있는 냄새다.
다른 하나는...
```

## 2. 의미 라벨링 금지

**하지 말 것**: 장면의 의미를 작가가 직접 선언

### 금지 표현 (절대 사용 금지)
- "이것이 첫 선택이다"
- "약함의 선택"
- "이것이 시작이었다"
- "소멸의 냄새"
- "전투가 끝난다" (의미 강조로 쓰인 경우)
- "그 순간 모든 것이 바뀌었다"
- "진짜 시작이었다"
- "특별했다"
- "운명이었다"

### 체크리스트
- [ ] 작가가 장면 의미를 직접 선언한 문장이 있는가?
- [ ] "이것이", "그것은", "이것은"으로 시작하는 의미 해설 문장이 있는가?
- [ ] 추상어가 단독으로 의미를 나타내는가?

### 대신: 행동, 반응, 결과로 의미 보여주기

나쁜 예:
```
이것이 첫 선택이다. 약함의 선택.
```

좋은 방향:
```
목 안쪽까지 올라온 힘을 삼켰다. 쓰면 끝낼 수 있었다. 하지만 아이가 내 손목을 잡고 있었다.
```

## 3. 추상어 남발 금지

### 금지 단어 (단독 문장으로 사용 금지)
- 소멸
- 운명
- 선택
- 본능
- 감각
- 공포
- 불안
- 진실
- 각성
- 존재

### 규칙
이 단어를 반드시 사용해야 하면 구체적인 장면, 물체, 행동, 신체 반응과 연결

### 체크리스트
- [ ] 추상어가 단독 문장으로 쓰였는가?
- [ ] 추상어가 구체적인 장면과 연결되어 있는가?

### 나쁜 예
```
소멸의 냄새.
선택한다.
각성이었다.
```

### 좋은 방향
```
낡은 동전 냄새. 살아 있는 사람에게서는 나면 안 되는 차가운 냄새가 섞여 있었다.
손끝이 먼저 굳었다. 아이가 잡은 손목이 더 따뜻했다.
손끝이 처음으로 떨렸다.
```

## 4. 감각 묘사는 상황 안에 녹인다

### 규칙
감각을 "설명"이 아니라 "경험"으로 표현

### 체크리스트
- [ ] 감각 묘사가 장면 밖에서 설명되고 있는가?
- [ ] "냄새가 났다. ~했다. ~했다" 식의 나열인가?
- [ ] 인물이 그 감각에 어떻게 반응하는가?

### 나쁜 예
```
금속. 낡은 철. 하지만 녹스는 냄새 아니다. 무너지는 냄새다. 썩음 같지만 썩음 아니다.
```

### 좋은 방향
```
손잡이를 쥔 손끝에 미세하게 쇳가루가 묻은 것 같았다. 오래된 동전 냄새가 목 안쪽에 걸렸다. 
땀과 세제 냄새 사이로, 살아 있는 사람에게서는 나면 안 되는 차가운 냄새가 섞여 있었다.
```

## 5. 인물의 감정은 선언하지 말고 반응으로 보여준다

### 규칙
감정 상태를 설명하지 말고, 그 감정의 신체적 반응을 보여주기

### 체크리스트
- [ ] "~하다. 10년 만이다." 식의 감정 선언이 있는가?
- [ ] "두려움이 몰려왔다", "놀랐다" 같은 감정 단어가 있는가?
- [ ] 그 감정의 신체 반응이 대신 표현되어 있는가?

### 나쁜 예
```
심장이 뛴다. 10년 만이다.
두려움이 몰려왔다.
놀랐다.
```

### 좋은 방향
```
손끝이 먼저 굳었다. 이어폰 줄이 손등에 걸렸는데도 빼낼 생각이 들지 않았다. 
10년 동안 한 번도 틀린 적 없던 감각이, 처음으로 방향을 잃었다.
```

- [ ] "약함의 선택" 같은 의미 제목이 포함되는가?

## 7. 독자에게 해설하지 않는다

### 규칙
독자가 느껴야 할 것을 작가가 대신 설명하지 말기

### 나쁜 예
```
이것이 첫 선택이다. 약함의 선택.
이것이 중요한 순간이었다.
그는 변했다.
```

### 좋은 방향
```
목 안쪽까지 올라온 힘을 삼켰다. 쓰면 끝낼 수 있었다. 하지만 아이가 내 손목을 잡고 있었다. 
나는 괴물의 힘 대신, 내 팔 하나로 버텼다.
```

### 체크리스트
- [ ] 작가의 설명이 독자의 이해를 돕는가, 아니면 강제하는가?
- [ ] 독자가 스스로 깨달을 수 있도록 구성되어 있는가?

## 8. 대사 전후에 자연스러운 반응을 넣는다

### 규칙
대사가 공중에 뜨지 않게 하기. 대사 직전-직후에 시선, 손동작, 침묵, 주변 반응 포함

### 나쁜 예
```
"오빠."
아이가 말한다.
```

### 좋은 방향
```
"오빠."
아이가 나를 봤다. 눈빛이 뭔가 다른 게 반사되고 있었다.
```

또는:
```
옆에 누군가 앉는다. 가벼운 무게.
"오빠."
이어폰을 빼고 싶었지만, 손가락이 움직이지 않았다.
```

### 체크리스트
- [ ] 대사 직전에 상황이나 신체 반응이 있는가?
- [ ] 대사 직후에 반응이나 행동이 있는가?
- [ ] 대사가 고립되어 있지는 않은가?

## 9. 반복 어휘 제한

### 금지 대상 (한 장면 내)
같은 단어를 과도하게 반복하지 않기:
- 냄새 (반복 시 "향", "내음", "것", 구체적 대상으로 대체)
- 괴물 (반복 시 "그것", "것", "놈", 구체적 특징으로 대체)
- 아이 (반복 시 "어린애", "것", 대명사로 대체)
- 선택 (반복 시 "결정", "길", 구체적 행동으로 대체)
- 10년 (반복 시 "그 시간들", 구체적 장면으로 대체)
- 감지 (반복 시 "느꼈다", "안다", "본다"로 대체)
- 다르다 (반복 시 구체적 차이로 표현)

### 체크리스트
- [ ] 같은 단어가 한 장면 내에서 5회 이상 나타나는가?
- [ ] 의도적인 리듬 효과인가, 아니면 무의식적 반복인가?

### 의도적 반복은 허용
```
손잡이를 잡고, 잡고 있고, 놓을 수 없다.
```
이런 식의 의도적 리듬은 괜찮음.

## 10. 전투 장면은 동작 나열이 아니라 목표와 압박으로 쓴다

### 규칙
전투에 "목표/압박/대가" 중 최소 3개 포함

### 6가지 필수 요소
1. **지켜야 할 대상** (아이)
2. **피해야 할 위험** (괴물의 발톱)
3. **쓸 수 없는 능력** (능력 흡수 불가)
4. **좁은 공간** (버스)
5. **시간 제한** (정거장 도착까지)
6. **선택의 대가** (능력 쓰면 아이 상실)

### 체크리스트
- [ ] 전투가 단순한 동작 나열인가? (괴물이 온다. 피한다. 친다.)
- [ ] 위의 6가지 중 최소 3개가 명확히 존재하는가?
- [ ] 주인공이 단순히 이기고 지는 것 외에 선택할 것이 있는가?

### 나쁜 예
```
괴물이 온다. 피한다. 친다. 다시 온다. 몸을 굴린다.
```

### 좋은 방향
```
괴물이 달려온다. 아이가 내 손목을 잡고 있다. 
피할 수 있다. 하지만 아이를 놓쳐야 한다. 
또는 능력을 쓸 수 있다. 하지만 그러면...
```

## 11. 최종 원고에서 작업용 메타 제거

### 반드시 제거할 항목
- "## 장면 1-A", "## 장면 1-B" 같은 장면 번호와 제목
- "Draft v3", "Draft v2" 같은 버전 표시
- "✅ 개선 사항", "✅ 어휘 단순화" 같은 체크박스
- "END OF DRAFT" 같은 마크
- "Draft v3 통계", "확장된 요소" 같은 작가용 설명
- 품질 점수, 평가 항목
- 메타 코멘트

### 체크리스트
- [ ] 제목이나 장면 번호가 최종 원고에 있는가?
- [ ] 버전 표시나 작가용 주석이 있는가?
- [ ] "✅", "⭐", "⏳" 같은 기호가 있는가?

## 12. 문장 리듬 최종 검사

### 검사 항목 (수정 전 체크)

**문장 길이 리듬**
- [ ] 같은 문장 길이가 5문장 이상 반복되는가?
- [ ] 한 문단이 매우 길거나 매우 짧은가?

**종결 리듬**
- [ ] "~다." 종결이 8문장 이상 연속되는가?
- [ ] 종결이 "~다", "~었다", "~았다", "~네" 등 다양한가?

**문장 구조 다양성**
- [ ] 명사 단독 문장이 3번 이상 연속되는가?
- [ ] "주어 + 동사" 단순 구조가 반복되는가?
- [ ] 복합 문장이나 비교 표현이 있는가?

**의미 표현**
- [ ] 추상어가 단독 문장으로 쓰였는가?
- [ ] 장면 의미를 직접 해설한 문장이 있는가?

**장면 흐름**
- [ ] 대사 앞뒤가 부자연스럽게 끊겼는가?
- [ ] 전투가 동작 나열로만 되어 있는가?
- [ ] 감각 묘사가 설명문처럼 분리되어 있는가?

## 13. 의인화 표현 금지

### 규칙
신체나 물체가 의도하는 대상으로 표현하지 말기. 구체적인 신체 반응으로 표현

### 금지 표현
- "눈이 떠진다" → "눈을 뜬다" (눈이 주체성 있게 표현)
- "코가 깨어난다" → "냄새가 올라온다" / "목 안쪽이 자극된다"
- "마음이 흔들렸다" → "손끝이 굳었다" / "숨이 얕아졌다"
- "몸이 움직인다" → "몸을 날린다" (몸이 주체가 아님)
- "시선이 모인다" → "본다" (시선이 모이는 게 아니라 보는 것)

### 체크리스트
- [ ] 신체 부위가 주체처럼 행동하는 문장이 있는가?
- [ ] 물체가 의도적으로 행동하는 표현이 있는가?
- [ ] 모두 구체적인 신체 반응으로 표현되었는가?

### 나쁜 예
```
마음이 흔들렸다.
눈이 떠진다.
코가 깨어난다.
```

### 좋은 방향
```
손끝이 먼저 굳었다. 입안이 바짝 말랐다.
목 안쪽이 자극된다. 냄새가 올라온다.
```

## 14. 능력 사용 시 신체 변화로만 표현

### 규칙
능력을 쓰려는 충동이나 능력의 효과를 **신체 변화**로만 표현. 추상적 설명 금지

### 능력 표현 금지
- "팔이 더 빨라질 것이다" (설명)
- "상처도 더 빨리 아물 것이다" (설명)
- "세상이 더 명확해질 것이다" (설명)
- "내가 인간을 포기하는 순간" (직접 설명)

### 능력 표현 허용 (신체 변화)
- "손가락 끝이 까맣게 변할 것 같다" (시각적 변화)
- "세상이 뚜렷해질 것 같다" (감각적 변화)
- "팔이 더 빨라질 것 같고" (신체 감각)
- "상처도 더 빨리 아물 것 같다" (신체 변화)
- "세상이 더 명확해질 것 같다" (의식 변화를 감각으로)

### 체크리스트
- [ ] 능력의 효과를 직접 설명한 부분이 있는가?
- [ ] 모든 능력 표현이 신체 변화(손가락, 피부, 시각, 청각)로 표현되었는가?
- [ ] "~할 것 같다"로 가능성을 표현했는가?

### 나쁜 예
```
능력이란 뭔가. 내가 사냥한 것들의 냄새를 맡는 것을 넘어, 
그들의 것을 내 것으로 만드는 것.
```

### 좋은 방향
```
손가락 끝이 까맣게 변할 것 같다. 세상이 뚜렷해질 것 같다. 
저 무게쯤은 아무것도 아닐 것 같다. 팔이 더 빨라질 것 같고. 
상처도 더 빨리 아물 것 같다.
```

## 15. 원고 수정 순서

원고를 완전히 새로 쓰지 말고, 아래 순서로 수정:

1. **AI식 문장 제거** (의미 라벨링, 장면 제목, 메타 설명)
2. **기계적 단문 리듬 완화** (문장 길이와 종결 다양화)
3. **감각 묘사를 장면 안에 통합** (설명 → 경험)
4. **감정 선언을 행동 반응으로 변환** (표현 → 반응)
5. **의인화 표현 제거** (신체 부위 의인화 → 구체 신체 반응)
6. **능력 표현 신체화** (추상 설명 → 신체 변화)
