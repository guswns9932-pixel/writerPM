# READABILITY_HARNESS: 중학생 수준 가독성 표준

**목표**: 중학생도 가볍게 읽을 수 있는 수준의 가독성 확보

**아님**: 문청스럽거나 지나치게 단순한 표현

---

## 1. 어휘 수준 관리

### 허용 어휘 (중학 교육과정 중심)

**일상적 단어** ✅:
```
냄새, 손끝, 버스, 발톱, 전투, 능력, 아이, 괴물
충동, 감각, 반응, 선택, 보호, 생존
```

**자연스러운 고급 어휘** ✅:
```
비명, 냉정함, 고립, 번아웃, 미스터리, 반전
무감각, 의도적, 비인간적
```

### 제한할 어휘 (회피 또는 설명 필요)

**지나치게 문학적** ❌:
```
소멸, 운명, 본질, 영혼, 절망, 순수, 경계
형이상학적, 초월적, 관조
```

**지나치게 기술적** ❌:
```
신경전달물질, 근력 증강, 신진대사, 효율화
```

**지나치게 일상적 (이상함 전달 어려움)** ❌:
```
"내가 뭐 했다", "되게 좋아", "살짝 이상"
```

### 어휘 사용 기준

**어려운 단어를 쓸 때**:
1. 문맥에서 의미가 명확해야 함
2. 대체 가능한 쉬운 단어가 없어야 함
3. 한 문단에 어려운 단어는 1-2개 최대

**예**:
```
냉정함을 유지하는 것. (문맥: 감정을 드러내지 않음)
비명을 지른다. (문맥: 소리를 낸다)
```

### 체크리스트
- [ ] 한 문단에 어려운 단어가 3개 이상인가?
- [ ] 어려운 단어의 의미가 문맥에서 명확한가?
- [ ] 어휘 수준이 일관적인가?

## 2. 문장 길이 관리

### 권장 길이 분포 (한 장면 기준)

| 길이 | 글자 수 | 비율 | 용도 |
|------|---------|------|------|
| 초단문 | 5-10자 | 10% | 강조, 임팩트 |
| 단문 | 10-20자 | 30% | 기본 |
| 중문 | 20-40자 | 40% | 흐름 |
| 장문 | 40자 이상 | 20% | 설명, 배경 |

### 나쁜 예
```
주인공은 지하철 7번 출구에서 올라오는 순간에 냄새가 먼저 다가왔고, 
그것은 10년 동안 계속되어 온 일상적인 냄새들과는 완전히 다른 무언가였다.
```
(너무 길고 무거움)

### 좋은 예
```
지하철 7번 출구를 올라오는 순간 냄새가 부딪친다.

10년 동안 맡던 것들. 땀, 옷감, 어제의 향수. 
그것들이 일렬로 계단을 올라온다.

그리고 뭔가 다른 것.
```
(길이 다양, 임팩트 있음)

### 측정 방법
- 장면별로 10문장을 뽑아서 평균 길이 계산
- 40자 이상 문장이 20% 이상이면 단순화 검토

### 체크리스트
- [ ] 같은 길이의 문장이 5문장 이상 연속되는가?
- [ ] 장문(40자 이상)이 30% 이상인가?
- [ ] 초단문(10자 이하)이 있는가?

## 3. 문체 일관성

### 기본 문체 (중학생 수준)

**권장**:
- 하다 → "한다" (존댓말 금지: "합니다")
- 되다 → "된다"
- 있다 → "있다" (있어요 금지)
- 다 → 종결사 기본

**금지** ❌:
```
~습니다 (존댓말)
~하옵니다 (과도한 존경)
~ㅂ시다 (명령)
~어/아야 해 (과도한 일상체)
```

### 시제 일관성

**기본 시제: 과거 진행형 (~했다, ~었다)**:
```
버스를 탔다. 손끝이 굳었다. 냄새가 올라왔다.
```

**현재 진행형 (~한다)** - 제한적 사용:
```
손끝이 굳는다. (감정의 순간성 강조)
```

### 체크리스트
- [ ] 시제가 일관적인가?
- [ ] 존댓말이나 과도한 존경어가 있는가?
- [ ] 문체가 급격히 바뀌는 부분이 있는가?

## 4. 주어 생략 기준

### 적절한 생략

**생략해야 함** ✅:
```
"내가 본다" → "본다"
"나는 앉는다" → "앉는다"
"내 손끝이 굳었다" → "손끝이 굳었다"
```

**생략하면 안 됨** ❌:
```
"버스가 온다" (버스가 주체 필요)
"아이가 손을 뻗는다" (아이의 주도성 강조)
```

### 과도한 생략 확인
- 한 문단에 주어 없는 문장이 70% 이상이면 가독성 저하

### 체크리스트
- [ ] 누가 하는 것인지 불명확한 문장이 있는가?
- [ ] 1인칭 주어가 반복적으로 나타나는가?

## 5. 사전 정의 필요 단어

### 첫 등장 시 설명이 필요한 단어

**예 1: "냄새"**
- 첫 등장: "손에 들었던 오래된 동전 냄새. 녹슬지는 않은, 하지만 무너지는..."
- 이후: "냄새" 단독으로 사용 가능

**예 2: "괴물"**
- 첫 등장: "옷이 찢어진다. 팔이 길어진다. 손가락이 늘어난다. 검은 손톱이 자라난다."
- 이후: "괴물", "그것", "놈"으로 부르기 가능

**예 3: "능력"**
- 첫 등장: 신체 변화로 표현 ("손가락 끝이 까맣게", "세상이 뚜렷해짐")
- 이후: "충동", "흡수", "능력" 등으로 직접 부르기 가능

### 첫 등장 설명 체크리스트
- [ ] 중요한 단어가 갑자기 등장하지는 않는가?
- [ ] 첫 등장 시 독자가 그것이 무엇인지 알 수 있는가?
- [ ] 설정 설명이 장면에 자연스럽게 녹아 있는가?

## 6. 가독성 시각적 배치

### 문단 길이

**권장**:
- 2-4문장으로 구성
- 한 문단 최대 8문장

**피해야 할 것**:
```
한 문장만 있는 문단 (너무 띄어나 보임)
10문장 이상 (모바일에서 피로)
```

### 장면 전환 표시

**권장**:
```
---

새 장면 시작
```

**최소 장면 길이**: 
- 500글자 이상 (너무 짧으면 분절된 느낌)

### 대사와 지문의 배치

**좋은 예**:
```
"오빠."

목소리가 맑다. 학교 가는 아이처럼.

아이가 나를 본다.
```

**나쁜 예**:
```
"오빠." 아이가 말한다. 목소리가 맑다. 학교 가는 아이처럼. 아이가 나를 본다.
```

### 체크리스트
- [ ] 한 문단이 10문장 이상인가?
- [ ] 한 문장만 있는 문단이 많은가?
- [ ] 대사와 지문이 뒤섞여 있는가?

## 7. 모바일 가독성 확인

### 화면 높이 기준 (스마트폰)

**한 화면에 보이는 양**:
- 약 4-5문장 (문장 길이에 따라 변동)
- 너무 적으면 분절감, 너무 많으면 피로

### 읽기 속도 최적화

**좋은 예** (빠른 읽음):
```
손끝이 굳었다. 냄새가 올라온다. 
아이가 손을 뻗는다. 괴물이 아이를 향해 돌아선다.
중얼거린다. "물러."
```

**나쁜 예** (느린 읽음):
```
주인공은 자신의 손끝이 굳어가는 것을 느꼈고, 
그것과 동시에 낯선 냄새가 코 안쪽으로 올라왔으며, 
그 순간 옆에 앉아 있던 아이가 갑자기 손을 뻗어서...
```

### 체크리스트
- [ ] 한 장면이 너무 길거나 너무 짧은가?
- [ ] 문장이 길어서 여러 줄로 나누어 읽히는가?
- [ ] 장면 전환이 명확한가?

## 8. 가독성 평가 체크리스트

### 최종 확인

| 항목 | 확인 사항 | 통과 |
|------|---------|------|
| 어휘 수준 | 한 문단 어려운 단어 3개 이상 | ✅ / ❌ |
| 문장 길이 | 장문 비율 20-30% | ✅ / ❌ |
| 문체 | 시제/존댓말 일관적 | ✅ / ❌ |
| 주어 생략 | 불명확한 주체 없음 | ✅ / ❌ |
| 첫 등장 설명 | 주요 단어 설명 완료 | ✅ / ❌ |
| 문단 길이 | 2-8문장, 평균 4-5문장 | ✅ / ❌ |
| 장면 전환 | 명확한 구분 | ✅ / ❌ |
| 모바일 가독성 | 화면에 4-5문장 | ✅ / ❌ |
