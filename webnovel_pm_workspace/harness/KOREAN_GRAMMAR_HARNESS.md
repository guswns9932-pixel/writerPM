# KOREAN_GRAMMAR_HARNESS: 문피아 스타일 한국어 문법

**목표**: 문피아 웹소설의 자연스러운 한국어 문법을 표준화

---

## 1. 주어 생략 규칙

### 기본 원칙
- 1인칭 주어는 극도로 생략
- 대사에서 주어 완전 생략
- 행동이 명확하면 주어 생략

### 생략 기준

**필수 생략**:
```
나는 본다 → 본다
내가 앞으로 나아간다 → 앞으로 나아간다
나는 선택했다 → 선택했다
```

**선택적 생략 (문맥에 따라)**:
```
내 손끝이 굳었다 → 손끝이 굳었다 (중요하면 "내 손끝")
나는 아이를 봤다 → 아이를 봤다
```

**생략 금지**:
```
버스가 온다 (버스는 독자 관점 필요)
괴물이 달려온다 (주체 명확화 필요)
아이가 손을 뻗는다 (아이의 주도성 강조 필요)
```

### 체크리스트
- [ ] 1인칭 "나는", "내가"가 과도하게 반복되는가?
- [ ] 행동의 주체가 불명확한가?
- [ ] 대사에 주어가 포함되어 있는가?

---

## 2. 자연스러운 조사 사용

### 주의할 조사 (과도 사용 방지)

**"-이/가" 사용 기준**:
- 새로운 정보, 강조 필요할 때만
- "손끝이 굳었다" ✅ (손끝의 상태 강조)
- "나가 본다" ❌ (부자연스러움, "본다"로)

**"-을/를" 사용 기준**:
- 목적어는 일반적으로 생략 가능
- "버스를 탔다" → "탔다" (버스가 명확한 맥락)
- "아이를 본다" → "아이를 본다" (대상 강조 필요)

**"-의" 대신 관계 표현**:
- "내의 손끝" ❌
- "내 손끝" ✅
- "아이의 손" → "아이 손" (자연스러운 경우)

### 체크리스트
- [ ] 같은 조사가 과도하게 반복되는가?
- [ ] 부자연스럽게 늘어진 조사 구문이 있는가?

## 3. 종결사 다양성

### 권장 종결사 배분 (한 장면 기준)

| 종결사 | 비율 | 용도 |
|--------|------|------|
| ~다 | 40-50% | 기본 종결 |
| ~었다 / ~았다 | 20-30% | 과거/완료 |
| ~네 | 5-10% | 발견/감탄 |
| ~야 | 5-10% | 강조/의지 |
| ~다고 | 5-10% | 간접 대사 |

### 나쁜 예 (종결사 반복)
```
탔다. 탔다. 탔다. 탔다. 탔다. 탔다.
```

### 좋은 방향
```
탔다. 손끝이 굳었다. 냄새가 올라온다. 
이게 뭐지? 이것이 처음이다.
```

### 체크리스트
- [ ] 같은 종결사가 5문장 이상 연속되는가?
- [ ] ~네, ~야, ~다고 같은 다양한 종결이 있는가?

## 4. 대화체와 문어체 구분

### 대사 (대화체) - 자유로운 문법

**허용**:
```
"오빠."
"이번엔 삼키지 마."
"뭐해?"
"괜찮아."
```

**금지**:
```
"오빠입니다."
"이번엔 삼키지 않으시기를 바랍니다."
```

### 지문 (문어체) - 표준 문법

**기본**:
```
몸을 날린다. 아이를 보호하기 위해.
손가락 끝이 까맣게 변할 것 같다.
```

**과도한 문어체 금지** (너무 딱딱함):
```
주인공이 몸을 날렸다. → 몸을 날린다.
그는 아이를 보호하였다. → 아이를 보호했다.
```

### 체크리스트
- [ ] 대사에 존댓말이나 과도한 존경어가 있는가?
- [ ] 지문이 너무 딱딱하게 일관되었는가?

## 5. 타이핑 감각 (자연스러운 한국어 리듬)

### "~ㄹ 것 같다" vs "~할 것 같다"

**"~ㄹ 것 같다" 사용 (더 자연스러움)**:
```
손가락 끝이 까맣게 변할 것 같다. ✅
세상이 뚜렷해질 것 같다. ✅
파고들 것 같았다. ✅
```

**"~할 것 같다" 사용 (과거/회상)**:
```
그때 할 것 같았던 실수. (과거 예상)
```

### 부자연스러운 표현 제거
- "~하 있다" ❌ → "~하고 있다" ✅
- "~해지고 있다" (어색) → "~해진다" (자연스러움)
- "~할 수 있었다" (문어) → "~할 수 있었다" (필요시 유지)

### 체크리스트
- [ ] "~할 것 같다"를 "~ㄹ 것 같다"로 변경해야 하는가?
- [ ] 불필요한 진행형 "~고 있다"가 반복되는가?

## 6. 단문과 복문의 균형

### 단문 (짧은 문장) 사용

**좋은 예**:
```
손끝이 굳었다. 냄새가 올라온다. 아이 손이 따뜻했다.
```

**과도한 단문** ❌:
```
다. 다. 다. 다. 다. (기계적)
```

### 복문 (연결) 사용

**좋은 예**:
```
손끝이 굳으면서 냄새가 올라온다.
아이 손이 따뜻했지만, 능력 충동이 더 강했다.
```

### 균형 기준
- 단문 50-60%
- 복문 (그리고, 하지만, ~면서) 30-40%
- 병렬 구조 10-20%

## 7. 문피아 특징 반영

### 문피아의 특징적 표현

**1) 감각 중심**:
```
"냄새가...", "손끝이...", "눈이..." (신체 감각 우선)
```

**2) 직설적 대사**:
```
"나는 네가 뭔지 알아." (단순, 강렬)
"이번엔 삼키지 마." (짧고 임팩트)
```

**3) 행동 중심**:
```
설명하지 말고, 하거나 한다. (행동만 표현)
```

**4) 반복적 리듬**:
```
"손끝이... 손가락이... 손목이..." (같은 부위 반복으로 리듬감)
```

**5) 시간 압박**:
```
"이제 3분이면 끝이다." (구체 수치)
"40초쯤이면 도착할 것이다." (예측)
```

### 체크리스트
- [ ] 감각 중심인가?
- [ ] 대사가 자연스럽고 직설적인가?
- [ ] 행동과 반응 중심인가?
- [ ] 리듬이 있는가?
