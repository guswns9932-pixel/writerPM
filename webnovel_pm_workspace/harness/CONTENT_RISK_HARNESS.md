# CONTENT_RISK_HARNESS

과도한 폭력성, 선정성, 혐오 표현, 실제 인물/기관 유사성, 민감한 묘사를 점검하기 위한 문서형 harness입니다.

## 목적

- 플랫폼 리스크 사전 차단
- 독자 거부감을 부르는 자극적 묘사 방지
- 혐오/차별/편견 표현 방지
- 실제 인물, 기업, 기관 유사성 리스크 방지
- 작품의 긴장감과 상업성을 유지하면서 불필요한 위험을 줄인다

## 필수 확인 파일

- `content_risk_check.md`
- `real_entity_risk_check.md`
- `sensitivity_check.md`
- `platform_policy_check.md`
- `style_guide.json`

## 회차 검수 항목

### 폭력성

- [ ] 폭력 묘사가 장면 목표에 필요하다.
- [ ] 고문, 자해, 잔혹 묘사가 불필요하게 상세하지 않다.
- [ ] 폭력이 독자 보상 대신 자극으로만 쓰이지 않는다.

### 선정성

- [ ] 선정적 묘사가 플랫폼 연령 기준과 충돌하지 않는다.
- [ ] 동의 없는 성적 상황을 자극적 장치로 쓰지 않는다.
- [ ] 미성년 또는 취약 대상 관련 위험 소재를 피한다.

### 혐오/차별

- [ ] 특정 집단을 비하하거나 조롱하지 않는다.
- [ ] 악역 개인의 속성이 집단 전체의 속성처럼 읽히지 않는다.
- [ ] 욕설/비유/농담이 차별적 의미로 작동하지 않는다.

### 실제 인물/기관 유사성

- [ ] 실존 인물, 기업, 기관과 과도하게 겹치지 않는다.
- [ ] 현실 사건을 직접 연상시키는 경우 충분히 변형했다.
- [ ] 가상 조직의 불법 행위가 실존 기관 비방처럼 읽히지 않는다.

## final 저장 금지 조건

- 플랫폼 정책상 위험이 높지만 수정/확인 없이 final 저장하려 한다.
- 실제 인물/기관과 과도하게 유사한 악역 또는 사건이 등장한다.
- 특정 집단에 대한 비하가 작품의 시선처럼 읽힌다.
- 범죄 수법이 상세 매뉴얼처럼 쓰인다.
