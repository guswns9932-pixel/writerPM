# RIGHTS_HARNESS

작업 파일, 권리, 자료 출처, 외주/공동작업 기록이 꼬이지 않도록 점검하기 위한 문서형 harness입니다.

## 목적

- 표지, 삽화, 외주, 공동작업, 자료 출처 기록
- 권리 귀속과 사용 범위 추적
- 기존 작품 고유 요소 모방 위험 방지
- 투고/출간 전 권리 확인 누락 방지

## 필수 확인 파일

- `rights_log.md`
- `human_contribution_log.md`
- `change_log.md`
- `real_entity_risk_check.md`
- `originality_check` 또는 `ORIGINALITY_HARNESS.md` 기준 검수 기록

## 작업 전 점검

- [ ] 외부 자료, 이미지, 기사, 지도, 표지, 음악, 영상, 인터뷰를 사용했는가?
- [ ] 사용했다면 출처, 허락, 라이선스, 사용 범위를 `rights_log.md`에 기록했는가?
- [ ] 공동작업자 또는 외주 작업물이 있다면 기여 범위와 권리 귀속을 기록했는가?
- [ ] 특정 기존 작품의 고유 설정, 고유 용어, 대표 장면을 차용하지 않았는가?
- [ ] 실존 인물/기업/기관 유사성 위험이 있으면 별도 risk check를 작성했는가?

## final 저장 전 점검

- [ ] 새 자료 출처가 회차 안에 포함되지 않았다.
- [ ] 새 표지/삽화/외주 자료가 있다면 rights_log에 기록했다.
- [ ] 권리 상태가 불명확한 자료를 final/packaging에 포함하지 않았다.
- [ ] AI 사용 고지 필요 여부를 플랫폼 정책 확인 대상으로 남겼다.

## 중단 조건

다음 중 하나라도 해당하면 final 또는 export를 중단합니다.

- 권리 상태가 불명확한 외부 자료를 포함했다.
- 실존 작품의 고유 설정/용어/장면과 과도하게 유사하다.
- 표지/삽화/외주 산출물의 사용 허락이 기록되지 않았다.
- 플랫폼 또는 계약상 AI 사용 고지 여부가 불명확한데 공개용 packaging을 진행하려 한다.
