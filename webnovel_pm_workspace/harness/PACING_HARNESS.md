# PACING_HARNESS

1000화 단위 장기 연재에서 거시적 페이싱(긴장 곡선, 이완 구간 비율, 피로 누적)을 점검하는 harness입니다.

---

## 목적

회차별 품질 점검(QUALITY_HARNESS)은 개별 화의 완성도를 봅니다. 하지만 50화 내내 긴장만 계속되거나, 이완 구간이 전혀 없거나, 클라이맥스가 너무 빨리 소진되는 문제는 개별 화를 볼 때는 보이지 않습니다.

이 harness는 arc 단위와 전체 연재 단위의 긴장 곡선을 관리해 독자가 피로하지 않으면서도 긴장감을 잃지 않게 합니다.

---

## 긴장 레벨 척도 (1~10)

| 레벨 | 설명 | 대표 장면 유형 |
|---|---|---|
| 1 | 일상 / 이완 / 인물 호흡 | 평화로운 일상, 배경 설명 |
| 2 | 잔잔한 복선 심기 | 독자만 감지할 불안감. 갈등 없음 |
| 3 | 사소한 갈등 또는 정보 노출 | 약한 긴장. 위험 없음 |
| 4 | 목표와 장애물 명확화 | 초반 긴장 형성. 결과 불확실 시작 |
| 5 | 중간 강도 갈등 | 결과가 불확실한 대결 또는 선택 |
| 6 | 위기감 형성 | 실패 가능성을 체감하는 상황 |
| 7 | 강한 위기 | 주인공이 진짜 위험에 처함 |
| 8 | 고강도 대결 또는 충격 반전 | 독자 심리 충격. 단기 지속 |
| 9 | 클라이맥스 직전 | 모든 것이 위태로운 상태 |
| 10 | arc/작품 클라이맥스 | 최대 긴장. 지속 불가. 작품에 1~2회 |

---

## 실행 트리거

| 트리거 | 유형 | 설명 |
|---|---|---|
| arc 종료 시 | **필수** | CONTEXT_COMPRESSION_HARNESS와 함께 실행 |
| 10화 단위 audit | **필수** | LONGFORM_HARNESS audit에 포함. 미실행 시 완료 보고 불가 |
| tension level 8 이상이 3화 연속 발생 시 | **즉시** | 강제 실행. relief episode 계획 없이 outline 금지 |
| 전체 회차의 25% 도달 시 (예: 250화, 500화) | **권장** | 전체 pacing curve 중간 점검 |

## 점검 1 — Arc 단위 페이싱 점검

`pacing_curve.json`의 해당 arc 항목을 열고 다음을 확인한다.

### 1-A. 평균 긴장 레벨 적절성

```
이번 arc의 평균 tension_level이 arc_tier의 max_average_tension 이하인가?
```

arc_tier별 기준:

| arc_tier | 해당 구간 | max_average_tension |
|---|---|---|
| early | 전체 1~30% | 5 이하 |
| mid | 전체 31~60% | 6 이하 |
| late | 전체 61~85% | 7 이하 |
| final | 전체 86~100% | 8 이하 |

- [ ] **기준 이하** — 정상
- [ ] **기준 초과** — 경고. 다음 arc 시작 전 tension 조정 계획 필수

### 1-B. Relief Episode 비율

```
이번 arc에서 tension 1~3 회차(이완 회차)가 전체의 최소 20% 이상인가?
```

계산: 이완 회차 수 ÷ arc 전체 회차 수 × 100

- [ ] **20% 이상** — 정상
- [ ] **10~20%** — 주의. 다음 arc에서 비율 보완
- [ ] **10% 미만** — 경고. 독자 피로 위험. relief episode 우선 배치 필요

### 1-C. 연속 고긴장 위반 여부

```
이번 arc 내에서 tension level 8 이상이 3화 연속으로 발생한 구간이 있는가?
```

- [ ] **없음** — 정상
- [ ] **있음** — 해당 구간 기록. 해소 방법 기술 (실제로 이미 발생했다면 다음 arc에서 보완)

### 1-D. 고긴장 후 이완 배치

```
tension 8 이상 회차 이후 3화 이내에 이완 회차(tension 1~3)가 있었는가?
```

- [ ] **있음** — 정상
- [ ] **없음** — 경고. 다음 배치에서 즉시 이완 회차 선배치

## 점검 2 — Relief Episode 충족 여부

이완 회차로 인정되는 조건:

**인정됨**:
- 인물 간 일상 또는 관계 심화 장면 위주
- 세계관 탐색 또는 배경 깊이 부여 위주
- 주인공 내면 성찰 또는 감정 회복 위주
- 복선 심기 위주의 조용한 전개
- 유머 또는 캐릭터 매력 발산 위주

**인정되지 않음**:
- 새로운 위기가 등장하는 회차 (tension 4 이상)
- 정보 폭탄 공개가 메인인 회차
- 전투 또는 생존 위기가 포함된 회차

최소 빈도: **10화당 최소 2회 이상** 이완 회차 포함.

---

## 점검 3 — 페이싱 피로도 감지 (Pacing Fatigue)

다음 신호 중 2개 이상이 동시에 감지되면 pacing fatigue로 판단한다.

| 신호 | 확인 여부 |
|---|---|
| 독자 보상 유형이 3화 이상 동일 (PATTERN_REPETITION과 겹침) | ☐ |
| 전체 회차의 15% 미만이 tension 1~3 구간 | ☐ |
| tension 7 이상 회차 비율이 전체의 40% 초과 | ☐ |
| 사용자 피드백에서 "패턴이 느껴진다", "무감각해진다" 언급 | ☐ |
| arc 2개 이상 연속으로 escalation 규칙 위반 | ☐ |

### Pacing Fatigue 감지 시 조치

1. 다음 배치 outline 작업 전 **relief episode 최소 2화 선배치**
2. `pacing_curve.json`의 `pacing_fatigue_triggers` 기록
3. 사용자에게 보고 후 확인

## 장기 연재 긴장 곡선 가이드 (1000화 기준 3막)

원고 작성 시 전체 구조에서 현재 위치를 확인하는 기준점.

### 1막 (EP001~EP300)
- **형태**: 완만한 상승
- **평균 tension**: 3~5
- **목표**: 독자와 주인공 유대 형성. 세계관 신뢰 구축.
- **핵심 beat**: EP001 훅, EP020 전후 첫 arc 클라이맥스(tension 7), EP100 전후 세계관 전환점
- **주의**: 이 구간에서 tension 8 이상은 원칙적으로 사용하지 않음

### 2막 (EP301~EP750)
- **형태**: 파동형 상승 (상승-하강 반복하며 전체 수준은 높아짐)
- **평균 tension**: 5~7
- **목표**: 독자 피로 방지 + 지속적 긴장 유지
- **핵심 beat**: EP300 전후 큰 선택(1막→2막 전환), EP500 전후 작품 중간 위기, EP700 전후 클라이맥스 준비
- **주의**: 파동형 구조를 유지. tension이 내려가지 않고 계속 높은 상태가 되는 것을 경계

### 3막 (EP751~EP1000)
- **형태**: 지속 상승 후 단일 클라이맥스 → 급격한 하강(resolution)
- **평균 tension**: 7~9
- **목표**: 모든 복선과 약속 회수. 클라이맥스 한 번만.
- **핵심 beat**: EP850~900 클라이맥스 준비, EP950 전후 최종 대결(tension 10), EP980~1000 결말 및 emotional landing(tension 2~3)
- **주의**: tension 10은 이 구간에서 1회만. 결말은 반드시 이완으로 끝냄

## 조치 (Corrective Action)

### 경미한 주의

- `pacing_curve.json` 해당 arc 항목에 메모 추가
- 다음 arc 계획에서 relief episode 비율 보완

### 중간 경고

- `run_report`에 경고 내용 포함
- 다음 arc outline 작성 전 pacing 조정 계획 사용자 확인

### 심각한 경고 (pacing fatigue 또는 연속 고긴장 위반)

- 다음 outline 작업 전 **relief episode 계획 필수**
- `halt_reason_code: PACING_FATIGUE_DETECTED` 기록
- 사용자 확인 전 다음 배치 진행 금지

```
  현재 tension 1~3 구간 비율: {{%}}

종합 판정: 정상 / 주의 / 경고
조치: {{없음 / relief episode 계획 / halt}}
```
