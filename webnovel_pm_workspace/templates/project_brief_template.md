## 기본 정보

- project_id: `{project_id}`
- working_title: `{working_title}`
- genre: `현대판타지 / 로맨스판타지 / 무협 / 아카데미 / 기타`
- target_platform_tone: `한국 웹소설 모바일 연재`
- target_readers: `예: 빠른 전개와 성장 보상을 선호하는 독자`
- initial_scope: `컨셉부터 1화 final까지`

- 핵심 재미:
- 독자에게 약속할 감정:
- 1화에서 반드시 보여줄 매력:
- 장기 연재에서 유지할 엔진:

## 금지 요소

- 특정 기존 작품의 고유 설정, 고유 용어, 대표 장면 모방 금지
- 특정 작가 문체 모방 금지
- 사용자 승인 없는 2화 이후 작성 금지
- 기존 final 파일 덮어쓰기 금지

## 최초 작업 범위

- [ ] 컨셉 후보
- [ ] project bible
- [ ] character bible
- [ ] worldbuilding / ability rules
- [ ] 1화 outline
- [ ] 1화 draft
- [ ] 1화 review
- [ ] 1화 revision
- [ ] 1화 final 후보

## 사용자 승인 게이트

- 1화 final 승인 전 허용 작업:
  - 컨셉, Bible, 1화 관련 작업
- 1화 final 승인 전 금지 작업:
  - 2화 이후 본문 작성
  - 다음 배치 자동 생성
