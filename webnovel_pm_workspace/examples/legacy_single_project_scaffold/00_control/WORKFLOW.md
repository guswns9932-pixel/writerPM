# 작업 흐름

## 절대 규칙

Codex는 사용자가 요청한 범위만 작업합니다. 다음 단계가 논리적으로 이어지더라도 사용자의 명시적 승인이나 지시가 없으면 진행하지 않습니다.

## 단계별 흐름

### 1단계: 프로젝트 브리프

- 작품 목표, 장르, 타깃 독자, 금지 요소를 정리합니다.
- 산출물: `PROJECT_BRIEF.md`

### 2단계: 컨셉 기획

- 로그라인, 핵심 재미, 차별점, 독자 후킹을 작성합니다.
- 산출물: `01_concept/CONCEPT.md`, `01_concept/HOOKS.md`

### 3단계: 설정과 인물 구축

- 세계관, 규칙, 시간선, 주요 인물, 관계를 작성합니다.
- 산출물: `02_worldbuilding/`, `04_characters/`

### 4단계: 1화 설계

- 1화 목표, 장면 구성, 엔딩 훅을 설계합니다.
- 산출물: `06_episode_001/EP001_OUTLINE.md`

### 5단계: 1화 작성과 검수

- 1화 초안을 작성합니다.
- 설정, 문체, 재미, 복선, 시간선, 독창성을 검수합니다.
- 산출물: `EP001_DRAFT.md`, `EP001_REVIEW.md`, `EP001_REVISION.md`

### 6단계: 사용자 승인

- 사용자가 1화를 검토합니다.
- 승인 전에는 2화 이후를 작성하지 않습니다.
- 승인 여부는 `APPROVAL_LOG.md`에 기록합니다.

### 7단계: 3화 단위 연재 작업

- 1화 승인 후에만 진행합니다.
- 한 번에 3화 단위로 개요, 초안, 검수, 수정본을 작성합니다.
- 다음 3화 묶음은 사용자의 지시가 있을 때만 시작합니다.
