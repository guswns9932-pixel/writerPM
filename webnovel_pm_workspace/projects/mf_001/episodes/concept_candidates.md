| **로그라인** | 10년 경력에 지쳐 무감각해진 퇴마사에게 아이 유령 하나가 달라붙는다. 문제는 그 유령이 사흘 뒤 주인공의 죽음을 예언하고 있다는 것. |
| **핵심 재미** | 죽음 카운트다운 + 퇴마 세계의 이면 폭로 + 번아웃 주인공의 재각성 |
| **1화 후킹** | 주인공이 아파트 복도에서 울고 있는 아이를 무시하고 지나친다 — 직업병처럼. 그런데 집 문을 닫은 순간, 아이의 목소리가 문 너머에서 들린다. "오빠, 사흘 있어." 주인공의 본명을. |
| **주인공 욕망/선택** | 표면: 살아남기. 근본: 왜 이 일을 시작했는지 다시 찾기. 매 회차마다 "도망치거나 직면하거나"의 선택이 반복된다 |
| **독자 보상** | 1화: 유령이 아는 정보가 주인공만 알 수 있는 것 → 소름 + 호기심 / 이후: 예언이 하나씩 맞을 때마다 긴장 배가 |
| **차별점** | "퇴마사"가 주인공이지만 무기력하게 시작. 유령이 조력자이자 시한폭탄 역할. 예언-검증-반전 구조로 회차 독립성과 장기 연결성 동시 확보 |
| **장기 연재 가능성** | arc 1: 사흘 생존 + 유령의 정체. arc 2: 유령을 만든 사건 추적. arc 3: 퇴마 세계 내부 권력 갈등. arc 4: 예언의 원천(신화적 존재) 대면. 자연스럽게 1000화 설계 가능 |
| **모방 위험 점검** | "퇴마" 장르 자체는 장르 문법. "죽음 예언 카운트다운"은 장르 문법. 고유 조합(번아웃 퇴마사 + 예언하는 아이 유령 + 본인 죽음 예언)은 신규 조합으로 판단. 특정 기존 작품 재현 없음 |

| 항목 | 내용 |
|---|---|
| **임시 제목** | 신들의 부고 |
| **장르** | 현대판타지 / 한국 신화 / 사무소 판타지 |
| **로그라인** | 현대 한국 어딘가, 비밀 정부 기관이 한국 신화 속 존재들을 관리한다. 어느 날 삼신할머니의 사망신고서가 접수된다. 출생과 운명을 관장하던 신이 죽었다 — 지금부터 태어나는 모든 인간에게는 운명이 없다. |
| **핵심 재미** | 한국 신화의 현대적 재해석 + 관료제 블랙코미디 + 우주적 위기를 책상머리에서 해결해야 하는 아이러니 |
| **1화 후킹** | 월요일 아침 9시. 주인공이 커피를 들고 자리에 앉는다. 결재함에 서류 하나. "망자 처리 신청서 — 신격(神格) 1호, 삼신할머니." 담당자 서명란에 이미 상관의 도장이 찍혀 있고, 메모 하나: "네가 처리해." |
| **주인공 욕망/선택** | 표면: 이 사태를 수습해서 짤리지 않기. 근본: 신들이 왜 현대에 남아서 인간과 공존하려 했는지 이해하기. 선택의 구조: 규정대로 처리할 것인가, 원칙을 깰 것인가 |
| **독자 보상** | 1화: 황당한 설정 + 블랙코미디 + "이게 진짜 위기다"라는 반전 인식 / 이후: 각 신화 존재가 등장할 때마다 한국 신화 지식 + 현대 재해석의 쾌감 |
| **차별점** | "신화 관리 공무원"이라는 설정. 한국 고유 신화(삼신할머니, 저승사자, 도깨비 등) 기반이지만 재해석. 우주적 위기를 서류 결재로 처리하는 역설적 구조 |
| **장기 연재 가능성** | arc 1: 삼신할머니 사망 원인 + 운명 없는 신생아들의 이상 현상. arc 2: 신들이 현대에 남기로 결정한 이유 추적. arc 3: 신들을 죽이고 있는 존재의 정체. arc 4: 신화와 현대 질서의 재편. 한국 신화 pantheon이 방대해 1000화 소재 풍부 |
| **모방 위험 점검** | "도깨비", "저승사자" 등 소재는 한국 전통 설화 공유 소재. "신화 관리 공무원" 설정은 고유 조합. 삼신할머니의 죽음으로 운명 시스템이 붕괴하는 구조는 신규. 특정 작품 재현 없음 |

## 후보 C — 《냄새로 본다》

| 항목 | 내용 |
|---|---|
| **임시 제목** | 냄새로 본다 |
| **장르** | 현대판타지 / 헌터물 / 도덕적 딜레마 |
| **로그라인** | 인간에 섞여 살아가는 괴물들. 주인공은 냄새로 그들을 구분하고, 쓰러뜨린 괴물의 능력을 흡수한다. 그런데 옆집 아홉 살 아이에게서 괴물 냄새가 난다. 사냥 못 하고 있다. |
| **핵심 재미** | 능력 흡수 성장물 + "괴물이란 무엇인가"의 철학적 갈등 + 이웃 아이라는 감정적 앵커 |
| **1화 후킹** | 출근길 버스. 승객 32명 중 11명에게서 냄새가 난다. 주인공은 창문 쪽 자리에서 이어폰을 끼고 눈을 감는다. 그런데 냄새 중 하나가 다가온다. 자리를 바꿔 주인공 바로 옆에 앉는다. 그리고 속삭인다. "나는 네가 뭔지 알아." |
| **주인공 욕망/선택** | 표면: 가장 강한 사냥꾼이 되기. 근본: 인간과 괴물의 경계가 어디인지 직접 확인하기. 선택 구조: 아이를 사냥하는가, 보호하는가 — 이 선택이 장기 축을 형성 |
| **독자 보상** | 1화: 긴장감 + 능력 설정의 흥미로운 소개 / 이후: 새 괴물 흡수 때마다 능력 조합의 쾌감 + 아이의 비밀이 조금씩 풀리는 미스터리 |
| **차별점** | 능력 흡수 성장물의 메커니즘을 "냄새"라는 감각으로 차별화. 도덕적 딜레마가 1화부터 설정되어 장기 긴장축으로 작동. 헌터물의 쾌감 + 윤리적 질문의 결합 |
| **장기 연재 가능성** | arc 1: 아이의 정체 + 첫 위기. arc 2: 사냥꾼 세계 내부 파벌 갈등. arc 3: 괴물들의 사회와 그 내부 규칙 발견. arc 4: 주인공 자신의 냄새(정체)에 대한 의문. 능력 흡수의 성장 곡선이 자연스럽게 1000화 커버 |
| **모방 위험 점검** | "헌터물", "능력 흡수" 메커니즘은 장르 문법. "냄새로 감지"는 독자적 감각 설정. "옆집 아이가 괴물"이라는 도덕적 딜레마 축은 신규. 기존 유사작과의 고유 조합 차별화 확인됨 |
