## 주인공 (이름 미정) — 28M, 사냥꾼

### 성격과 말투의 기초

- 10년 사냥으로 인한 번아웃 상태
- 감정 표현이 거의 없음
- 단어 선택이 건조하고 직설적
- 하지만 위기 상황에서는 바뀜 (아직 arc 1에서는 없음)

### 1화 샘플 대사

**일상 상황에서**:
```
"응."
"몰라."
"다시."
```

**생각할 때** (내면 독백):
```
"버스 승객 32명. 그 중 11명이 무엇인지 나는 안다."
```

**위협을 감지했을 때**:
```
"냄새가... 다르다."
```

**아이를 보호하려 할 때** (처음으로 감정이 나타남):
```
"물러서."
(이것이 주인공이 할 수 있는 최대의 감정 표현)
```

### 말투 특징

- 대사가 매우 짧음 (1~3단어)
- 과거형이나 설명이 없음
- 명령조로 끝남
- 혼잣말 때도 마찬가지로 짧음
- arc 진행에 따라 조금씩 길어질 예정

### 주의사항

- 주인공은 아직 감정을 느끼고 있지 않음을 표현해야 함
- 말투의 단조로움이 "번아웃"을 드러내는 스타일
- "약함"을 선택하는 순간에도 대사는 최소한으로 유지

## 아이 (이름 미정) — 9F, 미스터리 캐릭터

### 성격과 말투의 기초

- 외모: 순수한 9살 아이처럼 보임
- 내면: 노련하고 어딘가 절망적
- 말투: 9살처럼 순수해 보이지만 문법이 약간 어색함
- 주인공을 보는 눈: 방어적이고 판단적

### 1화 샘플 대사

**처음 마주했을 때**:
```
"오빠, 나는 네가 뭔지 알아."
```

**주인공의 본명을 부를 때** (가장 위협적인 순간):
```
"[주인공의 본명], 이번 선택이 결정한다."
```

**전투 중** (거의 대사 없음):
```
(아이는 말보다 행동으로 표현)
```

### 말투 특징

- 문법이 약간 경직되어 있음 (예: 존댓말이 아니지만 어색함)
- 9살 아이 같은 순수함과 성인 같은 절망감의 조화
- 주인공에게 말할 때만 "오빠"라는 호칭 사용
- 대부분 선언적 문장으로 끝남
- 질문이 거의 없음 (이미 답을 알고 있는 듯한 느낌)

### 주의사항

- 아이는 주인공을 이미 알고 있음을 암시해야 함
- 순수해 보이면서도 불안한 이중 말투 유지
- arc 진행에 따라 더 많은 대사와 정보 공개
- 1화에서는 신비로움을 최대한 유지

## 배경인물 (일반 승객 + 괴물들)

### 일반 승객

- 거의 대사 없음
- 괴물에게 위협받을 때만 "비명", "도움말" 정도
- 구체적인 이름이나 특징 없음

### 괴물들

- 1화에서는 본격 대사가 없음
- 신호음, 으르렁거림, 물리적 위협만으로 표현
- 인간의 언어를 쓰지 않음 (아직은)

## Drift 감지 기준 (매 10화마다 체크)

체크 항목:
- [ ] 주인공의 대사가 점점 길어지고 있는가? (arc에 맞게 길어져야 함)
- [ ] 아이의 말투가 변하고 있는가? (신비로움이 유지되는가?)
- [ ] 주인공의 내면 독백이 감정으로 채워지고 있는가? (arc에 맞게)
- [ ] 배경인물들의 대사가 늘어나고 있는가? (1화 정도 수준 유지)

## 성장 예상

### Arc 1 (EP 001-100) 진행에 따른 주인공 말투 변화

- **초반 (EP001-030)**: 한 단어 대사 주도
- **중반 (EP031-070)**: 2~5단어 대사 증가
- **후반 (EP071-100)**: 완전한 문장이 나타남 (아이와의 관계로 인한 감정 각성)

### Arc 2 (EP 101-300) 진행에 따른 아이 말투 변화

- **초반 (EP101-150)**: 여전히 신비로움 주도
- **중반 (EP151-250)**: 자신의 배경 일부 공개, 대사 증가
- **후반 (EP251-300)**: 더 많은 감정 표현

## 주의: 말투는 성격

- 주인공의 짧은 말투 = 번아웃
- 아이의 어색한 문법 = 인간이 아닐 가능성
- 이 두 말투의 충돌과 조화가 1화의 감정 중심
