# ai_usage_disclosure_note - 사각지대

필요 시 AI 사용 고지 문구 초안을 기록한다. 실제 고지 여부와 문구는 플랫폼 약관, 계약 조건, 사용자 판단에 따라 결정한다.

## 운영 전제

- 이 workspace는 외부 API 기반 자동 생성 프로그램이 아니다.
- `OPENAI_API_KEY` 설정이나 외부 자동화 앱을 사용하지 않는다.
- 사용자가 Codex 안에서 자연어로 지시하고, Codex가 repository 파일을 생성/수정/검수하는 방식으로 운영한다.

## 고지 문구 초안

### 짧은 문구

> 본 작품은 작가의 기획, 선택, 수정, 검수 과정에서 AI 보조 도구를 활용했습니다.

### 상세 문구

> 본 작품은 작가가 제공한 컨셉, 설정 방향, 피드백, 승인 과정을 바탕으로 AI 보조 도구를 활용해 초안 작성, 검수, 수정 계획 정리에 도움을 받았습니다. 최종 공개 여부와 내용에 대한 책임 및 창작적 결정은 작가에게 있습니다.
