# human_contribution_log - 사각지대

사용자가 직접 선택, 수정, 승인한 창작적 기여를 기록한다. 이 파일은 작품의 인간 창작 기여, 의사결정, 승인 이력을 보존하기 위한 작업 로그다.

## 기록 기준

- 사용자가 직접 제공한 소재, 제목, 장르, 방향성, 피드백을 기록한다.
- 사용자가 선택한 컨셉, 승인한 final, 거절한 제안도 기록한다.
- Codex가 생성한 내용과 사용자의 창작적 결정이 섞이지 않도록 구분한다.
- 법률 판단 문서가 아니며, 권리/계약 판단이 필요하면 별도 전문가 검토가 필요하다.
