# real_entity_risk_check - 사각지대

실제 인물, 기업, 기관과의 과도한 유사성을 점검한다.

## 점검 기준

- 실존 인물과 이름, 직업, 사건, 외형, 말투가 과도하게 겹치지 않는가
- 실존 기업/기관을 연상시키는 명칭과 불법 행위 묘사가 결합되지 않는가
- 특정 지역/직업/기관을 사실처럼 비방하지 않는가
- 실제 사건을 차용했다면 충분히 변형되어 있으며 출처/위험을 기록했는가
- 법적 판단이 필요한 경우 사용자 확인 또는 전문가 검토가 필요한가

## 금지

- 실제 기업/기관을 망루의 직접 모델로 확정하지 않는다.
- 실존 인물의 고유 사건, 말투, 이력을 villain으로 옮기지 않는다.
