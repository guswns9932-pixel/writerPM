# sensitivity_check - 사각지대

특정 집단 비하, 편견, 차별적 묘사를 점검한다.

## 점검 기준

- 성별, 인종, 국적, 지역, 장애, 질병, 종교, 성적 지향, 연령, 직업군을 고정관념으로 소비하지 않는가
- 악역의 속성이 특정 집단 전체의 속성처럼 읽히지 않는가
- 농담, 비유, 욕설이 특정 집단 비하로 작동하지 않는가
- 피해 경험이나 정신적 고통을 자극적 장치로만 쓰지 않는가
- 필요한 경우 대체 표현 또는 장면 축소를 검토했는가

## 수정 우선순위

1. 특정 집단을 조롱하는 표현 제거
2. 실제 집단과 가상 조직의 연결 약화
3. 악역 개인의 선택과 조직 논리를 구분
4. 주인공 내면 독백의 편견성 점검
