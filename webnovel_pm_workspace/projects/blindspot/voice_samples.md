# voice_samples.md

## 목적

- `사각지대` 주요 인물의 말투, 문장 길이, 내면 독백 방식을 고정한다.
- 회차별 캐릭터 voice drift를 방지한다.
- 사용자 피드백 “주인공 말투가 조금 가볍다. 더 건조하고 짧은 말투로 바꾸고 싶다.”를 이후 수정 계획과 대사 검수 기준에 반영한다.
- 이 파일은 원고를 직접 수정하지 않고, 이후 수정 요청이 있을 때 기준으로 사용한다.

## 공통 규칙

- 말투 수정은 기본적으로 `TEXT_ONLY`, `STYLE_ADJUSTMENT`, `CHARACTER_VOICE` 범위로 제한한다.
- 주인공의 욕망, 결핍, 선택 원칙, 능력 규칙, canon 변경으로 확대하지 않는다.
- 기존 final 파일은 직접 수정하지 않고 새 버전으로만 반영한다.
- 사용자가 “바로 반영”이라고 지시하지 않으면 `feedback_application_plan`을 먼저 작성한다.
