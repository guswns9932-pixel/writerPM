# rights_log - 사각지대

표지, 외주, 공동작업, 자료 출처, 권리 귀속을 기록한다. 이 파일은 작업 관리용이며 법률 자문을 대체하지 않는다.

## 권리 관리 원칙

- 외부 자료를 사용하면 출처, 사용 허락, 라이선스, 사용 범위를 기록한다.
- 표지/삽화/로고/지도/설정 자료 등 비원고 산출물도 기록한다.
- 공동작업자 또는 외주 기여가 있으면 계약/승인 상태를 기록한다.
- 특정 기존 작품의 고유 설정, 고유 용어, 대표 장면, 특정 작가 문체를 모방하지 않는다.
