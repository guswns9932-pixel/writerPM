# webnovel_pm_workspace

이 작업공간은 Codex 안에서 자연어 지시만으로 한국 웹소설을 기획, 작성, 검수, 수정하기 위한 문서 중심 워크스페이스입니다.

## 사용 원칙

- 이 프로젝트는 API 기반 외부 프로그램이 아닙니다.
- OpenAI API 연결, `OPENAI_API_KEY`, 실제 LLMClient, 서버, 웹 UI, FastAPI, Streamlit, React, 외부 자동 실행 앱을 만들지 않습니다.
- Codex는 사용자가 명시한 작업 범위만 수행합니다.
- Codex는 사용자의 승인 없이 다음 단계로 임의 진행하지 않습니다.
- 모든 결과물은 이 작업공간 안의 파일로 저장합니다.

## 목표

1. 한국 웹소설을 컨셉부터 1화까지 기획, 작성, 검수, 수정합니다.
2. 사용자가 1화를 검토하고 승인하면, Codex가 사용 가능한 작업 범위 안에서 3화 단위로 계속 작성합니다.
3. 매 회차마다 설정, 문체, 재미, 복선, 시간선, 독창성을 검수합니다.
4. 수정 사항은 변경 이유와 함께 파일로 남깁니다.

## 권장 진행 순서

1. `00_control/PROJECT_BRIEF.md`에 작품의 기본 목표와 금지 사항을 정리합니다.
2. `01_concept/CONCEPT.md`와 `01_concept/HOOKS.md`에서 핵심 컨셉과 독자 후킹 요소를 만듭니다.
3. `02_worldbuilding/`과 `04_characters/`에서 설정과 인물을 정리합니다.
4. `03_plot/`에서 1화까지의 플롯을 확정합니다.
5. `06_episode_001/`에서 1화 초안, 검수, 수정본을 작성합니다.
6. 사용자가 1화를 승인하면 `07_episode_batches/`에서 3화 단위 작업을 시작합니다.

## 주요 폴더

- `00_control/`: 작업 범위, 승인 기록, 진행 상태 관리
- `01_concept/`: 장르, 로그라인, 차별점, 후킹 요소
- `02_worldbuilding/`: 세계관, 규칙, 금지 설정, 시간선
- `03_plot/`: 전체 줄거리, 장기 떡밥, 회차별 개요
- `04_characters/`: 인물 프로필, 관계, 욕망, 결핍
- `05_style/`: 문체, 대사 톤, 금지 표현, 서술 규칙
- `06_episode_001/`: 1화 초안, 검수, 수정본
- `07_episode_batches/`: 1화 승인 이후 3화 단위 작업
- `08_review/`: 회차별 검수 결과
- `09_revision/`: 수정 요청과 반영 기록
- `10_exports/`: 사용자에게 전달할 최종본
- `templates/`: 반복 사용 템플릿
- `checklists/`: 검수 체크리스트
- `archive/`: 폐기 또는 보류된 아이디어
